# Arm model for the headset

Generated by `scripts/build_client_assets.py`; do not edit by hand.

- `so101.json` is the joint tree and mesh layout read from the packaged
  `so101_new_calib.urdf`. See
  `src/lerobot_teleoperator_quest/models/PROVENANCE.md` for its source commit
  and checksum.
- The `.stl` files are **modified** copies of the meshes in
  `Simulation/SO101/assets` of <https://github.com/TheRobotStudio/SO-ARM100> at
  that same commit. Each was simplified to at most 2,500 triangles (1,200 for
  the servo body) and rewritten as binary STL, so a headset can draw two arms
  twice each. They are for display only and are not dimensionally exact.
